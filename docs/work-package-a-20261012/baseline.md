## 页面与异常基线

| 场景 | 诊断结果 | 页面推导（非浏览器实测） |
|---|---|---|
| 首次无结果 | 缺少带来源和日期的有效推荐文件 | 空行显示原因，没有自动生成初始化结果的GET行为 |
| 已有结果核验过期 | 5行变0行，total_count=0，audit_pending=true | loadSignals用空数组覆盖旧列表并继续轮询 |
| 更新元数据删除窗口 | 旧CSV仍在、meta缺失，被判未就绪 | 读取返回空；计算失败后仍可能空屏 |
| 核验/生成失败 | health不可用；job failed并有受控错误 | 错误信息依赖状态消息；列表有内容时常驻错误栏缺失 |
| 内存注册器重建 | 旧job不存在；新HealthCache首读ready=false | 结果依赖重新核验，任务解释无法恢复 |
| 风险禁止新买入 | 5个候选均保留，suggested_weight全部0 | 读取器未传独立风险权限，排名与操作含义不够清楚 |
| 正常筛选为空 | 同日合法0行CSV被判ready=false | 与不可用结果共用空态提示 |

基线复现及验收映射见 [设计第3/8节](design.md)。F03元数据删除窗口为隔离文件模拟，删除时机由生产源码确认；F04行情源断开使用可控异常替身；F05不是实际服务重启。
